# 🦊 Black Fox Music (Чёрный Лис)

> **Версия 0.2.0**  
> Премиальный музыкальный плеер для Android в эстетике **Liquid Glass** с интеграцией YouTube Music, встроенной оффлайн-загрузкой, автоматической миграцией из ВКонтакте и поддержкой версий треков без цензуры.

---

## ✨ Что нового в версии 0.2.0

### 🔄 Полная миграция медиатеки из ВКонтакте
- **Импорт без паролей**: Достаточно указать свой VK ID, никнейм или ссылку на открытый профиль.
- **Интеллектуальное сопоставление**: Поиск треков по исполнителю, названию и альбому в наивысшем студийном качестве.
- **Круговой индикатор прогресса**: Наглядное отображение прогресса сопоставления (`СколькоПеренесено / СколькоВсего`) с отображением текущей песни в реальном времени.
- **Оффлайн-загрузка в память**: Возможность перед стартом миграции выбрать скачивание всех перенесенных треков на устройство с отдельным круговым индикатором загрузки (`СколькоСкачано / СколькоНужноСкачать`).
- **Автоподписка на любимых артистов**: Если у пользователя перенесено более 6 треков одного исполнителя, приложение автоматически подписывается на него в разделе «Мои артисты».
- **Перенос плейлистов и Избранного**: Воссоздает структуру всех альбомов и плейлистов из VK и наполняет «Любимое».

### 🎬 Версии без цензуры и музыкальные видео
- Официальные релизы многих лейблов в аудиоформате идут с цензурой (Radio Edit). Black Fox решает эту проблему:
- Фильтр поиска **«Видео (без цензуры)»** и карусель видеоверсий в результатах поиска.
- Кнопка **«Версия без цензуры (Видео)»** в полноэкранном плеере: в один тап находит официальные видеоклипы и премьеры текущей песни и мгновенно переключает аудиопоток на версию без цензуры.

### 🌟 Подписки на артистов и свежие новинки
- Раздел **«Мои артисты»** в медиатеке со списком отслеживаемых исполнителей.
- Баннер **«Новинки артистов»** на Главной: показывает только реальные релизы подписанных исполнителей за последние 30 дней.
- Сортировка альбомов и синглов в карточке артиста от самых новых к старым.

### 🎨 Кастомные темы акцентов (Dynamic Liquid Themes)
- 7 готовых палитр оформления: Неоновый оранжевый (Fox Orange), Изумрудный, Киберпанк, Фиолетовый аметист, Океанический синий, Рубиновый, Золотой янтарь.
- Все кнопки, рамки, индикаторы, волны и ползунки гармонично адаптируются под выбранную цветовую тему.

### 🖐 Перетаскивание треков и порядок добавления
- Новые добавленные треки в плейлисты и «Любимое» всегда появляются **сверху списка**.
- Удобное перетаскивание (Drag & Drop) за полоски слева от обложки для ручной сортировки порядка.

## 🎧 Основные возможности плеера

- **Онлайн-стриминг и поиск**: Полноценный каталог треков, синглов, альбомов и видеоклипов без авторизации и рекламы.
- **Оффлайн-хранилище**: 
  - Загрузка в наилучшем качестве (до 320 kbps).
  - Фоновый менеджер очереди закачек с поддержкой экрана блокировки.
  - Раздел «Скачанные» с отображением занятого места и быстрым удалением.
- **Фоновое воспроизведение и Lock Screen**:
  - Нативная реализация AndroidX Media3 `MediaSessionService`.
  - Управление воспроизведением и перемотка из системной шторки и с экрана блокировки.
- **Медиатека и плейлисты**:
  - Создание собственных плейлистов с кастомными обложками из галереи.
  - Поиск по своей локальной медиатеке.
  - Быстрый экспорт и импорт всей коллекции в файл JSON в один клик.
- **Интеллектуальные режимы прослушивания**:
  - **Fox Flow**: Персональная бесконечная волна рекомендаций, основанная на вкусах пользователя.
  - **Случайное из сохранённого**: Бесконечный микс из любимых и скачанных композиций.

## 🛠 Технологический стек

- **Язык**: Kotlin 2.0+
- **UI**: Jetpack Compose, Material 3, Liquid Glass / Glassmorphism shaders
- **Аудиодвижок**: AndroidX Media3 (ExoPlayer + MediaSession 1.5+)
- **База данных**: Room Database (SQLite) + Kotlin Coroutines Flow
- **Сеть и парсинг**: OkHttp 4, Kotlinx Coroutines, InnerTube API Engine, VK Audio Engine
- **Изображения**: Coil Compose (асинхронное кэширование обложек)

## 🚀 Сборка проекта

Для сборки проекта требуется **JDK 17** и **Android SDK** (API 26–35):

```bash
# Клонирование репозитория
git clone https://github.com/lismas-lab/BlackFoxMusic.git
cd BlackFoxMusic

# Сборка debug APK
./gradlew assembleDebug
```

Готовый файл APK располагается по пути:  
`app/build/outputs/apk/debug/app-debug.apk`
