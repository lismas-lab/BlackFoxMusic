# 🦊 Black Fox Music (Чёрный Лис)

> **Версия 0.0.1**  
> Современный плеер для Android с эстетикой **Liquid Glass**, каталогом YouTube Music, оффлайн-загрузками и нативной поддержкой фонового воспроизведения.

---

## ✨ Ключевые возможности

- 🎧 **Онлайн-поиск и каталог**: Мгновенный поиск треков, исполнителей и альбомов через InnerTube API без авторизации и рекламы.
- 🦊 **Стиль Liquid Glass**: Премиальный тёмный интерфейс (`#08090C`) с матовым размытием стекла и акцентным неоновым оранжевым (`#FF5E1E`).
- ⚡ **Скачивание треков и альбомов**: 
  - Загрузка прямых MP3-потоков высокого битрейта (до 320 kbps).
  - Круговой индикатор прогресса закачки с отображением процентов (`0%..100%`).
  - Оффлайн-хранилище в локальной файловой системе и базе Room.
- 📱 **Фоновое воспроизведение и Lock Screen**:
  - Полноценный AndroidX Media3 `MediaSessionService` с типом `mediaPlayback`.
  - Музыка продолжает играть при сворачивании и блокировке экрана.
  - Интерактивный виджет в шторке быстрых настроек и на экране блокировки с обложкой, названием и ползунком перемотки.
- 📂 **Плейлисты и Избранное**:
  - Быстрое добавление в «Избранное» в один клик.
  - Создание и редактирование собственных плейлистов.
- 🔁 **Полноэкранный плеер**:
  - Управление воспроизведением, перемотка, кнопки Next / Previous и зацикливание очереди.

---

## 🛠 Технологический стек

- **Язык**: Kotlin 2.0+
- **UI**: Jetpack Compose, Material 3, Custom Glassmorphism Shaders
- **Аудиодвижок**: AndroidX Media3 (ExoPlayer + MediaSession 1.5+)
- **База данных**: Room Database + Coroutines Flow
- **Сеть и парсинг**: OkHttp, Ktor Client, InnerTube Engine
- **Загрузка изображений**: Coil Compose

---

## 🚀 Сборка проекта

Для сборки проекта требуется **JDK 17** и **Android SDK** (API 26–35):

```bash
# Клонирование репозитория
git clone https://github.com/lismas-lab/BlackFoxMusic.git
cd BlackFoxMusic

# Сборка debug APK
./gradlew assembleDebug
```

Готовый файл APK будет находиться по пути:
`app/build/outputs/apk/debug/app-debug.apk`
