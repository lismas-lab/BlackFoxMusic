# Техническое задание (ТЗ)
## Проект: Мобильное приложение «Black Fox Music» (Чёрный Лис)

---

### 1. Общие сведения и назначение

* **Название проекта:** Black Fox Music («Чёрный Лис»).
* **Платформа:** Android.
* **Минимальная версия:** Android 8.0 Oreo (API Level 26).
* **Целевая версия:** Android 15 (API Level 35).
* **Основной стек:** Kotlin, Jetpack Compose, Jetpack Media3 (ExoPlayer), Room SQLite, Ktor/OkHttp, Coil, NewPipeExtractor.
* **Назначение:** Персональный музыкальный плеер с гибридной архитектурой: полноценный онлайн-поиск по мировому каталогу музыки (на базе YouTube Music InnerTube API), возможность оффлайн-скачивания треков и альбомов на устройство, воспроизведение локальных файлов, эргономичное управление плейлистами и уникальный интерфейс в стиле **Liquid Glass** с акцентами **Black Fox**.

### 2. Дизайн-система «Black Fox & Liquid Glass»

#### 2.1. Цветовая палитра
| Элемент | HEX / Значение | Назначение |
| :--- | :--- | :--- |
| **Obsidian Dark (Фон)** | `#08090C` / `#0D0E12` | Основной фон всего приложения (абсолютный контраст для OLED) |
| **Glass Surface (Стекло)** | `Color.White.copy(alpha = 0.05f .. 0.08f)` | Тело полупрозрачных плавающих карточек, списков и шторки |
| **Glass Border (Кайма)** | `1.dp`, градиент от `#FFFFFF` (15%) к `transparent` | Тончайшая кайма преломления света по краям стеклянных элементов |
| **Fox Orange (Лисий акцент)** | `#FF5E1E` (основной), `#FF7536` (свечение) | Кнопка Play/Pause, сердечко «Избранное», ползунок Seek Bar, бейджи |
| **Text Primary** | `#FFFFFF` | Названия треков, заголовки экранов, имена артистов |
| **Text Secondary** | `#8E909F` | Длительность, год альбома, подписи к трекам |
| **Text Muted / Icons** | `#525464` | Неактивные иконки навигации, разделители |

#### 2.2. Правила стиля Liquid Glass (Жидкое стекло)
1. **Скругления (Squircles):** Радиусы скругления карточек — `18.dp` – `24.dp`, для кнопок — `12.dp` – `16.dp` или круглые (`CircleShape`).
2. **Аппаратное размытие (Backdrop Blur):**
   * На устройствах Android 12+ (API 31+) используется аппаратный `Modifier.blur(16.dp)` для слоев, находящихся под мини-плеером, верхней панелью поиска и шторками.
   * Для версий API 26–30 используется fallback-градиент с высокой степенью затемнения (`#0D0E12` с альфа 88%).
3. **Эффект парения (Elevation & Shadows):** Стеклянные карточки не имеют резких черных теней — они выделяются тонкой белой градиентной каймой сверху и мягким рассеянным внутренним свечением.
4. **Fox Glow:** Интерактивные элементы с лисьим цветом имеют легкое неоновое размытие оранжевого цвета (`#FF5E1E` с прозрачностью 25%) для создания эффекта горящего угля.

### 3. Архитектура приложения

Архитектура строится по принципам **Clean Architecture + MVI/MVVM**:

```
app/
 ├── presentation/          // UI на Jetpack Compose
 │    ├── theme/            // Black Fox Theme, Color, Type, LiquidGlassModifier
 │    ├── screens/
 │    │    ├── search/      // Экран поиска (треки, альбомы, артисты)
 │    │    ├── album/       // Экран альбома с треклистом
 │    │    ├── artist/      // Экран артиста с дискографией
 │    │    ├── playlist/    // Экран плейлиста и диалог добавления
 │    │    ├── player/      // Полноэкранный плеер и мини-плеер
 │    │    └── downloads/   // Экран скачанной оффлайн-музыки
 │    └── components/       // Reusable GlassCard, FoxButton, TrackItem, SearchBar
 ├── domain/                // Бизнес-логика и сценарии использования
 │    ├── model/            // Domain-модели: Track, Album, Artist, Playlist
 │    └── usecase/          // SearchMusicUseCase, DownloadTrackUseCase, ManagePlaylistsUseCase...
 ├── data/                  // Источники данных
 │    ├── network/          // InnerTube API клиент, парсеры метаданных и аудио-потоков
 │    ├── local/            // Room Database (Entities, DAOs, TypeConverters)
 │    ├── repository/       // Реализация интерфейсов репозиториев
 │    └── download/         // Media3 DownloadManager / WorkManager
 └── service/               // Фоновый сервис воспроизведения MediaSessionService
```

### 4. Функциональные требования по модулям

#### 4.1. Модуль каталога и онлайн-поиска (YouTube Music InnerTube)
1. **Поисковая выдача:**
   * Отправка запросов с задержкой ввода (`debounce = 350ms`), чтобы не нагружать сеть при печати.
   * Фильтры выдачи:
     * `Все` (сводный экран: топ-песни, топ-альбомы, топ-артисты);
     * `Песни` (вертикальный список треков с длительностью, исполнителем и обложкой);
     * `Альбомы` (сетка 2 колонки с большими квадратными обложками, годом и типом: LP/EP/Single);
     * `Исполнители` (круглые аватары и количество подписчиков/треков).
2. **Экран альбома (`AlbumScreen`):**
   * Получение данных по `browseId` альбома.
   * Большая обложка в высоком разрешении (замена параметров в URL на `=w1080-h1080`).
   * Шапка: название альбома, имя артиста (кликабельно), год выпуска, общее количество треков и суммарная длительность.
   * Кнопка «Воспроизвести всё», кнопка «В случайном порядке» (Shuffle).
   * Кнопка **«Скачать альбом целиком»** (ставит все треки в очередь загрузчика).
   * Треклист: порядковый номер трека, название, длительность, кнопка добавления в плейлист `+` и меню действий `...`.
3. **Экран исполнителя (`ArtistScreen`):**
   * Фото артиста в шапке с эффектом параллакса и размытия в стекло.
   * Раздел «Популярные треки» (топ-5 или топ-10).
   * Раздел «Альбомы и Синглы» (горизонтальная или вертикальная сетка альбомов).

---

#### 4.2. Модуль воспроизведения (Media3 Audio Engine)
1. **Фоновое воспроизведение (`PlaybackService`):**
   * На базе `androidx.media3.session.MediaSessionService`.
   * Воспроизведение продолжается при блокировке экрана, переходе в другие приложения и в режиме энергосбережения.
2. **Системное уведомление (Media Notification):**
   * Отображение обложки трека, названия, артиста.
   * Кнопки: «Предыдущий», «Play/Pause», «Следующий», «Лайк / Избранное».
   * Интерактивная полоса перемотки (Seek bar) прямо в шторке Android.
3. **Обработка внешних событий:**
   * Пауза при отключении Bluetooth-наушников (Noisy Intent).
   * Управление аппаратными кнопками гарнитуры.
   * Приоритет аудиофокуса (при входящем звонке плеер встаёт на паузу).
4. **Управление очередью:**
   * Режимы: обычный, повтор трека, повтор всей очереди, перемешивание (Shuffle).
   * Возможность просматривать текущую очередь треков в отдельной стеклянной шторке.

---

#### 4.3. Модуль скачивания и оффлайн-режима
1. **Принцип работы с аудио-ссылками:**
   * Прямая ссылка на аудиопоток запрашивается непосредственно перед стартом загрузки.
   * Аудиофайл (M4A / Opus) сохраняется в изолированную директорию приложения (`context.getExternalFilesDir(Environment.DIRECTORY_MUSIC)`).
2. **Обложки:**
   * Обложка альбома сохраняется в локальный кэш картинок, чтобы трек отображался с картинкой даже при полном отсутствии интернета и авиарежиме.
3. **Экран «Загрузки / Оффлайн»:**
   * Показывает список всех загруженных треков.
   * Индикатор статуса загрузки для активных закачек (прогресс-бар в лисьем цвете).
   * Возможность удалить скачанный файл для освобождения памяти.
   * Индикатор: если трек уже скачан, в любом списке (в поиске, альбоме, плейлисте) возле него загорается аккуратная оранжевая иконка стрелки оффлайн-доступа.

---

#### 4.4. Модуль плейлистов и эргономика (1-Click Actions)
1. **Плейлист «Избранное»:**
   * Системный неизменяемый плейлист.
   * Доступен на главном экране в виде первой крупной карточки с лисьим сердцем.
   * Добавление: один клик по сердечку на карточке трека, в мини-плеере или на полном экране.
   * Анимация: сердечко вспыхивает огненно-оранжевым свечением и дает тактильный отклик (Haptic Feedback).
2. **Пользовательские плейлисты:**
   * Возможность создавать неограниченное число плейлистов (например, «В дорогу», «Тренировка», «Chill»).
   * Автоматическая генерация обложки плейлиста (коллаж из первых 4 треков) или установка своей.
3. **Шторка быстрого добавления в плейлисты (`AddToPlaylistBottomSheet`):**
   * Вызывается свайпом трека вправо или нажатием на иконку `+`.
   * Содержимое шторки:
     * Верхняя строка: поле быстрого создания `[+ Название нового плейлиста]` с кнопкой «Создать и добавить».
     * Список существующих плейлистов с чекбоксами. Нажатие ставит чекбокс и мгновенно привязывает трек.
     * Закрытие шторки свайпом вниз без лишних подтверждений.

### 5. Схема данных (Room Database)

#### 5.1. Таблица треков (`tracks`)
* `trackId` (String, Primary Key) — YouTube Video ID.
* `title` (String) — Название трека.
* `artist` (String) — Имя исполнителя.
* `artistId` (String?) — ID исполнителя в YouTube Music.
* `album` (String?) — Название альбома.
* `albumId` (String?) — ID альбома.
* `durationSeconds` (Long) — Длительность в секундах.
* `thumbnailUrl` (String) — Сетевой URL обложки.
* `localThumbnailPath` (String?) — Локальный путь к сохранённой обложке.
* `localAudioPath` (String?) — Локальный путь к скачанному файлу (null, если трек только в онлайне).
* `isDownloaded` (Boolean) — Флаг доступности оффлайн.
* `downloadedAt` (Long?) — Временная метка загрузки.

#### 5.2. Таблица плейлистов (`playlists`)
* `playlistId` (Long, Primary Key, AutoGenerate) — Идентификатор плейлиста.
* `name` (String) — Название.
* `isFavoriteSystem` (Boolean) — true только для «Избранного».
* `customCoverPath` (String?) — Пользовательская обложка.
* `createdAt` (Long) — Дата создания.

#### 5.3. Таблица связей треков и плейлистов (`playlist_track_cross_ref`)
* `playlistId` (Long) — Foreign Key на `playlists.playlistId` (CASCADE).
* `trackId` (String) — Foreign Key на `tracks.trackId` (CASCADE).
* `addedAt` (Long) — Время добавления (для сортировки по дате).
* `orderPosition` (Int) — Порядковый номер трека в плейлисте (для ручной сортировки).
